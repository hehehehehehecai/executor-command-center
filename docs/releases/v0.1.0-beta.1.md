# EXECUTOR v0.1.0-beta.1

发布日期：2026-09-04

版本类型：公开 Beta / prerelease

## 发布范围

`v0.1.0-beta.1` 是 EXECUTOR 的首个公开 Beta。它提供 Preview/Connected Onboarding，以及 Project Galaxy、Flight Log、Mission Control、Decision Archive、Copilot 五个只读项目工作区。

Connected 模式通过 Production GitHub App 读取用户明确授权的单个仓库，支持 First Sync、Webhook 增量同步、每日对账、Manual Resync、Project Brief、Decision Record 与 Evidence Link。GitHub 权限保持只读，不创建 Issue、Pull Request，不修改源码或仓库设置。

## 安全与数据边界

- Production Supabase 与 Vercel、GitHub App、Staging 资源相互隔离。
- public 表启用 RLS，敏感写入经受限 RPC；Service Role 仅在服务端使用。
- Webhook 使用 raw-body HMAC、payload 上限、delivery 幂等和乱序保护。
- server-only secret 不进入客户端 bundle、仓库、发布说明或执行报告。
- Repository 内容被视为不可信输入，不能扩大权限或改变系统合同。

## 已知限制

- 当前面向个人开发者，不支持团队、支付、BYOK、多模型、完整源码/Diff 扫描或公开项目页。
- Issue Draft 仅为草稿，不会自动发布。
- 不承诺 Production SLA、固定安全响应时间或修复时间。
- 外部平台可用性、配额与成本受对应账户计划约束；长期趋势告警和成本自动化仍待后续增强。
- 私密安全报告备用联系人和通用数据保留期限仍待确认。
