# 首发美术资产政策

版本：1。冻结日期：2026-09-10。适用单元：TASK-ART-04-01 / WU-ART-04-01。

## 一、适用范围与首发状态

首发采用 `css-procedural` 模式，仅使用 CSS 星点、网格、辉光和几何装饰；生产图片数量为 0。本政策冻结现有装饰边界，不新增视觉资产、布局、主题、字体、数据语义或交互实现。

以下未来资产规则是准入合同，不能视为已经批准引入图片、格式、生成器或加载器。实际清单保持空数组。

## 二、装饰与真实内容边界

真实信息始终来自 DOM 文本和数据。项目名、状态、数值、按钮、证据和导航不得由图像承载；不得以图片替代真实文本、数据、可访问名称或交互控件，也不得仅靠装饰颜色表达信息。

未来图像仅能提供不影响理解和操作的装饰。移除该图后，真实信息、证据引用、状态判断与导航操作必须仍然完整。`contentBearing` 必须为布尔值 `false`，并经实际内容审查确认；填入 `false` 本身不能替代审查。纯装饰性无法确认时不得准入。

## 三、来源、许可与准入责任

来源记录必须能够追溯原始材料、作者或权利主体以及原始凭据。生产许可必须另行核验，明确生产用途是否获准、使用范围、限制条件、授权凭据和本项目准入批准记录。来源可追溯不等于生产许可；已知来源、用户审过风格图或旧图已通过，均不能替代新资产的生产许可。

未来资产提交者负责提供可核验材料；准入审核须分别检查来源、许可和纯装饰性。许可或纯装饰性无法确认时不得准入。不得虚构许可证、权利归属或生成器授权，也不得把暂缺凭据写成已获许可。许可证或准入批准引用必须能供审核者独立核验，单纯声明“已授权”不足以准入。

## 四、权威清单与目录规则

唯一资产清单为 `public/art/executor/asset-manifest.json`。本版本是严格包含三个字段的 JSON 对象：`schemaVersion` 为整数 `1`，`mode` 为字符串 `css-procedural`，`assets` 为空数组。不得添加其他字段、演示资产、占位图、远程链接或附图。

未来资产的 `path` 必须是相对于 `public/art/executor/` 的目录内规范相对文件路径，并在清单中唯一。禁止绝对路径、盘符路径、UNC 路径、远程 URL、协议相对地址、data URI、反斜杠、空段、`.` 或 `..` 路径段；不得用编码或规范化差异绕过边界。规范化后的路径与实际文件解析结果均须位于该目录内，禁止通过符号链接或目录联接逃逸。路径大小写和扩展名必须与文件精确一致，不能依赖模糊匹配。

清单自身是元数据文件，不是图像资产。该目录内除此之外的任何未登记文件默认拒绝；不得因扩展名未知或文件未被识别而静默放行。登记本身也不代表许可、格式或内容已获批准。

## 五、未来资产记录字段合同

以下 13 个字段仅描述未来获准资产记录的最低合同，不向本版本 `assets` 添加记录。任何未来清单内容或模式变化均须先走第八节重新批准流程。

| 字段 | 类型与约束 | 核验要求 |
| --- | --- | --- |
| `id` | 非空字符串；全清单唯一且稳定 | 与批准记录对应，不复用其他资产身份 |
| `path` | 非空规范相对路径字符串；全清单唯一 | 按第四节检查路径和实际文件，精确匹配大小写与扩展名 |
| `purpose` | 非空字符串 | 说明纯装饰用途与使用位置；不得包含替代真实信息的用途 |
| `source` | 对象，含 `origin`、`rightsHolder`、`evidence` 三个非空字符串 | 分别提供原始来源、作者或权利主体、可核验原始凭据；凭据链接仅为溯源元数据，不是运行时资源下载授权 |
| `license` | 对象，含 `evidence`、`productionScope`、`conditions`、`approvalReference` 四个非空字符串 | 分别对应许可凭据、生产使用范围、条件限制及本项目准入批准；必须独立于来源核验，不得以未知或待确认材料准入 |
| `sha256` | 64 位小写十六进制字符串 | 对实际交付文件字节重新计算并精确匹配 |
| `width` | 正整数 | 与实际图像的像素宽度一致，符合另行批准的用途尺寸 |
| `height` | 正整数 | 与实际图像的像素高度一致，符合另行批准的用途尺寸 |
| `sizeBytes` | 正整数，不超过 `307200` | 与实际交付文件的字节数一致 |
| `format` | 非空字符串 | 必须属于届时明确批准的格式，且与文件实际编码和扩展名一致；当前批准集合为空 |
| `loading` | 字符串，值为 `lazy` | 未来装饰采用懒加载，不阻塞真实内容和操作；本批不实现加载器 |
| `fallback` | 对象，含 `strategy` 和非空字符串 `description` | `strategy` 仅为 `existing-css` 或 `none`，分别表示复用已批准 CSS 或取消装饰；说明失败后的可读、可操作行为，不引入替换图片 |
| `contentBearing` | 布尔值，固定为 `false` | 结合实际图像人工确认纯装饰性，不能只检查字段值 |

## 六、尺寸、大小、格式与加载

`width`、`height` 必须是实际文件像素尺寸的正整数。具体使用位置、渲染尺寸及适用尺寸上限须逐资产确认，目前待确认；不得把风格参考图尺寸当作已批准的生产尺寸。

单资产硬上限为 **300 KiB，即 307200 字节**，按交付文件实际字节数核验。超过上限默认拒绝，不能通过改名、压低登记值或拆分同一资产规避，必须重新批准。

首发生产图像格式允许集合为空。未来格式、生成器和运行时实现均未批准，标记为待确认；识别参考文件为 PNG 并不批准 PNG 进入生产。

未来获准的装饰资源采用 `lazy` 懒加载，不阻塞 DOM 文本、数据和控件。加载失败时复用已批准 CSS 或取消装饰，真实内容仍可阅读，按钮和导航仍可操作；不得临时从外部下载替代图，也不得用含真实信息的图片充当降级内容。本批没有新增图像加载器或失败替代实现。

## 七、可访问性与降级

装饰不拦截指针或键盘操作，不进入 Tab 焦点序列和可访问树，不覆盖焦点标识、标题、控件、状态、来源、Evidence、错误或撤权信息。CSS 装饰不得产生承载信息的伪元素文本。

未来若使用装饰图像元素，应提供空替代文本，并仅在必要的装饰元素自身隐藏可访问语义；不得隐藏包含真实文本或控件的祖先。装饰不能成为阅读或操作的前提。

尊重 Reduced Motion：禁用或最小化非必要动效，不用闪烁装饰表达状态。关闭动效、隐藏装饰或加载失败后，信息、证据与操作仍然可用。

## 八、重新批准门槛

以下六类变更均须重新批准：生产图进入首发、真实内容图、单资产超过 300 KiB、新格式、运行时加载器、外部 CDN。在明确批准并完成必要政策和版本调整前，现行规则仍默认拒绝这些变更；提出申请不等于准入，本节不是允许真实内容图的自动例外。

未来任何新图仍须逐张交用户作视觉确认，来源和生产许可另行审查。旧版 20 图的批准只属于原图和原版本，不涵盖新资产。涉及政策、清单、格式、生成器或实现的变更须明确批准后再实施；不能借本批合同提前引入资产或开启后续开发。
